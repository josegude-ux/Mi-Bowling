# MI BOWLING 3.3.31 · Buscador de jugadores

- «Resultados oficiales» → «Buscar jugador»: busca en todos los jugadores de la clasificación (cualquier club) por nombre, apellidos, nombre de uso o club; todas las palabras deben coincidir; ordenado por posición; máx. 25. Cada resultado abre la ficha.
- Se actualiza al escribir sin perder el foco del teclado.
